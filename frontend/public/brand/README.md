# Brand assets

Place the official logo file here (for example `logo.svg`) and point the app at it:

```
NEXT_PUBLIC_BRAND_LOGO=/brand/logo.svg
NEXT_PUBLIC_BRAND_NAME=Deloitte
```

The logo artwork is intentionally **not** included or recreated in this repository. Obtain
the official file from your brand portal and follow its usage guidelines (clear space,
minimum size, colour on light/dark backgrounds). When `NEXT_PUBLIC_BRAND_LOGO` is unset the
navigation shows a plain text wordmark instead.
